Logic Land — ดินแดนแห่งเหตุผล
เกมฝึกคิดเชิงคำนวณ 4 ด่าน 20 ภารกิจ สำหรับนักเรียนชั้นประถมศึกษาปีที่ 6
==================================================

วิธีเปิดเล่น (ใช้ได้ทันที ไม่ต้องติดตั้ง)
1. แตกไฟล์ ZIP ให้เป็นโฟลเดอร์ก่อน (อย่าเปิดจากในไฟล์ ZIP โดยตรง)
2. ดับเบิลคลิก index.html เปิดด้วย Chrome / Edge / Safari
3. กด "เริ่มเกม" กรอกชื่อและรหัสนักเรียน เลือกตัวละคร แล้วเริ่มผจญภัย
   ครั้งต่อไปกด "เล่นต่อ" ระบบบันทึกความคืบหน้าในเครื่องให้อัตโนมัติ

นำขึ้นเว็บไซต์
- อัปโหลดทั้งโฟลเดอร์ (index.html, css, js, assets) ไปยังโฮสต์เว็บแบบ static ได้เลย
  เช่น GitHub Pages, Netlify, Google Sites (ฝังผ่านลิงก์), เซิร์ฟเวอร์โรงเรียน
- เก็บโครงสร้างโฟลเดอร์ไว้เหมือนเดิม

เสียง
- 🎵 เปิด/ปิดเพลงพื้นหลัง   🔊 เปิด/ปิดเสียงเอฟเฟกต์ (มีทุกหน้า)
- เพลงจะเริ่มหลังแตะหน้าจอครั้งแรก ตามข้อกำหนดของเบราว์เซอร์

การควบคุม
- เมาส์ หรือแตะหน้าจอ รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

สำหรับคุณครู
- กติกา ผลทดสอบ และเฉลยที่ครูยืนยัน: README_LOGICLAND.md
- แก้ไขเนื้อหา: js/content.js (เฉลยทุกข้อครูยืนยันแล้ว)
- ดูคะแนนรายภารกิจ: ในเกม > สรุปคะแนน
- ความคืบหน้าบันทึกในเบราว์เซอร์ของแต่ละเครื่อง (เปลี่ยนเครื่องจะเริ่มใหม่)
